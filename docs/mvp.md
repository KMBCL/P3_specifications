# Minimal Viable Product (MVP)

Pour ce projet, le MVP est estimé avec les fonctionnalités suivantes:
# Phase 1:
- S'inscrire en tant qu'élève / tuteur
- Se connecter
- Possibilité d'assigner tuteur / élève
- Communiquer

Pourquoi: le coeur du projet est le soutien scolaire de l'élève avec l'aide du tuteur. La priorité doit être la mise en relation entre les deux parties. La communication permet une ébauche de soutien scolaire.

# Phase 2:
- Planifier des rendez-vous
- Affichage calendrier

Pourquoi: la prise de rendez-vous permet de structurer le rythme u soutien.

# Phase 3:
- Gestion des tâches assignées / personnelles

Pourquoi: permet de formaliser le travail entre rendez-vous
